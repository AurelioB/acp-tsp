# Reference TSP integration research for acp-tsp

Sources are per-section URLs; [INFERENCE] marks unobserved claims.

## Protocol primer (common to all three)
- Transport: each message is an APC string `ESC _ tsp ; <verb> [;k=v]* ; <body> ESC \`. Program->terminal verbs: q(query), o(open surface), f(frame of ops), b(blob), t(palette), x(close). Terminal->program: r(reply), e(event). Bodies > apc limit (default 65536 UTF-8 bytes) are chunked with shared `c=<id>`, all but the last carrying `m=1`. (docs/tern.md; crates/octet-tern/src/frame.rs)
- Handshake: program sends `{q:hello,v:[1],app,ver?,features?}` then a DA1 sentinel `ESC [ c`. Tern answers hello before DA1. Reply `{v,term,ver,kinds,features,apc,credits,cols,cell,dark,reduceMotion}`. Detected via `TERM_PROGRAM=tern` (octet also `TERN_PANE_SOCKET`). tmux/screen/zellij swallow APC so probing is skipped/fails. (pi-tern lib/tsp.ts, docs/NATIVE-FINDINGS.md; octet client.rs)
- Program hello `features` opt into terminal input (e.g. `edit`, `undo`, `send`); this is separate from the terminal reply's features (`scroll`, `dock`, `blobs`, `settle`, `adopt`, `program-palette`, `reduce-motion`, `aside`, `styles`, `flow`). (docs/tern.md; TSP-ENCODINGS.md)
- Regions: a surface root's first frame adds fixed regions `main`, `dock`, `layer` as children OF THE SURFACE ID (not as parents of nodes). Getting this wrong yields `unknown id main` errors and a blank pane. (pi-tern NATIVE-FINDINGS.md)
- Flow control: default 2 unacked frames per surface; terminal sends `{ev:ack,sf,s}`; sender waits on credit. Errors arrive as `{ev:error,sf,s,op,msg}` and are the primary debugging signal. (octet client.rs; pi-tern TSP-ENCODINGS.md)

## 1. hermes-for-tern (Python, MIT, ~10 stars)
- Structure: `src/hermes_for_tern/` (launcher, app, rpc, state, views, editor, design, demo_backend) + tests + pyproject; entry `__main__.py` -> `launcher.main`. Uses `uv`. (github.com/thefullctx/hermes-for-tern)
- How Tern launches it: `--install` renames the real `hermes` launcher to `hermes.before-tern` and writes a sh shim `exec python -m hermes_for_tern "$@"`; reversible `--uninstall`. Outside Tern/short of required capabilities it `os.execv`s the original Hermes (passthrough). `TERN_TSP=0`/`--plain` disable. (launcher.py)
- Connect gate: `tern_sdk.connect(app="hermes", version="0.1.0", features=("edit","undo","send"))`; requires kinds {col,card,md,editor,tool,el} and `caps.has("dock")`, else passthrough. Opens `mode="inline"`, `title="Hermes"`, `role="hermes.session"`; sends stylesheet + program palette (if `program-palette`) + SVG blobs (if `image`+`blobs`). (launcher.py, app.py, design.py)
- Backend: private bidirectional JSON-RPC (newline-delimited) to a Hermes child launched as `<hermes> --run-module tui_gateway.entry`; own process group; reader thread; methods `client.capabilities{server_requests:true}`, `session.create`, `session.interrupt`, `config.set`, `approval.received`, `session.close`; events arrive as `{method:"event",params:{type,payload,session_id}}`; server->client requests `approval`/`clarify` are answered by id. Not ACP. (rpc.py, app.py)
- TSP mapping (state.py reducer; views.py builders):
  - reasoning.delta -> `section` thought (md stream; folds to `pondered for Ns`); message.start/delta/interim/complete -> `card`+`md` assistant streamed; user -> bare card.
  - tool.start/complete -> `tool` node with name/target/status/exit/took, body `diff` or clipped `code`; `search_files` -> tree of md/text hits; `delegate_task`/subagent.* -> nested `agent` nodes; todo.updated -> `checklist` errands + `meter` ring.
  - session.usage -> `delivered` line + context `meter` + status `seg`; status.update -> activity row (`spinner`+`shimmer`+`elapsed`); notification.show/clear -> `toast`/dispatch notes; background.complete; error/notice; request.cancel.
  - Composer = `editor` node (role composer) + status bar `seg`(send/stop) + `effort` ring; approvals/clarifications = `card` with `html.button`s answered by clicks or digit keys.
- Inputs: `EditEvent` offsets are UTF-16 and validated against `len` (editor.py Draft, own undo); `Key` events for paste/backspace/arrows/ctrl. Effort ring -> `config.set(key="reasoning", value=hermes_effort(level))`, mapping `off`->`none`; clamps echoed via `reasoning_effort_wire`.
- Pain/TODO: only 7 effort levels exposed (Hermes `ultra` unreachable; silent clamping); `reasoning.available` is misnamed (reply text) and ignored; unused server requests answered `-32601` with a user notice; output clipped at 48000 chars with an explicit notice; no ACP.
(README.md, app.py, state.py, views.py, editor.py, design.py)

## 2. pi-tern (TypeScript, MIT)
- Two paths. (a) Extension: never writes TSP frames by design, because pi-tui frames are multi-write synchronized-output transactions and a second writer tears them; it only sends the `hello` probe and uses the Tern CLI + daemon relay (`$TERN_PANE_SOCKET`, u32LE+JSON framing) and a file-based mailbox to a Luau plugin. (b) Native mode (opt-in, v1.0.0): the `pi-tern` launcher probes Tern and, only in a Tern **agent block**, runs pi under a loader hook that hands rendering to Tern. (README.md, docs/ARCHITECTURE.md)
- Launch/connect: `native/handshake.mjs` sends hello+DA1 with retries (race is real: same pane 633B reply vs 6 timeouts over 2.4s), classifies failure (timeout/unexpected-reply/no-hello-reply/no-raw-mode/not-interactive/multiplexer). `/tern agent-setup` writes Tern settings keys `new_blocks:"Agent"` and `agent_command:<launcher>` (backup first). Extension probe reads reply via `ctx.ui.onTerminalInput`.
- Native TSP used: inline surface with `main`+`dock` regions; transcript is a **rows mirror** (one `rows` node) not semantic nodes; composer is a real `editor` node driven by `edit`/`undo`/`send` events; `suspend`/`resume`; opt-in `adopt`. hello features `["edit","undo","send"]`. (docs/NATIVE-FINDINGS.md)
- Pain/workarounds (excellent field notes): regions must be added under the surface id or ops silently fail; `listen:false` does NOT suppress `error` events in Tern 0.5.0; `tern capture` does not expose inline TSP surfaces (use the TSP record + event round-trips); Node DEP0205 warning leaks to the pty; `blob` is not a frame op (it is a plugin API) so image bytes must be inlined as `{k:image,p:{data,mime}}`; only `md` nodes can carry clickable `file://` links; pi sets process.title so use `pgrep -P`. Not wired yet: scroll, settle, blobs/image, styles, aside, program-palette, adopt restart. (TSP-ENCODINGS.md, NATIVE-FINDINGS.md)

## 3. octet / crates/octet-tern (Rust)
- Location: the crate exists on PR #480 (0.8.2 release train, consolidated head 88a545ff1) and PR #503, commit 555e8d13…; it is NOT in main's workspace members. Modules (src/): wire.rs, frame.rs, client.rs, tty.rs, theme.rs, reconcile.rs, scene.rs, bin/octet_tern_demo.rs. (github.com/skaft-software/octet/pull/480, /pull/503; docs/tern.md)
- Crates/async: deps are only serde, serde_json, toml, and libc (unix). No `tern-sdk` dependency; no async runtime in the crate — it is synchronous blocking I/O over the tty. `#![deny(unsafe_code)]` at crate root; `tty.rs` alone carries `#![allow(unsafe_code)]` (raw mode, poll, read). The wider octet agent uses tokio but the TSP client does not. Crate speaks TSP v1 and mirrors omp's `@oh-my-pi/pi-wire` `tsp.ts`. (crates/octet-tern/Cargo.toml, lib.rs)
- How Tern connects: octet's renderer thread owns one inline surface `octet.session` via `TernClient::connect_shared_input("octet", version, &["edit"])`; it does NOT own stdin — the frontend's single input owner feeds replies through `observe()`/`apply_hello`. Detection `TERM_PROGRAM=tern`; policy `--tern auto|on|off` (config `tern`, env `OCTET_TERN`/`OCTET_TUI_TERN`) published once; outside Tern it keeps the ANSI renderer. Regions `main` (transcript/welcome), `dock` (working+composer), `layer` (pickers/reports/overlays). (tui/view/tern.rs, docs/tern.md)
- Messages: q hello/blobs; o open/adopt (inline|screen); t palette (dark/light token maps + names); f frames with positional ops; b content-addressed blob (64-hex SHA id, mime, base64 body, validated); x close(keep). Inbound r hello/blobs and the full e event set: ack, resize, theme, motion, visible, toggle, select, activate, action, change, edit, focus, error, gone. `scroll` op gated on `hello.features` scroll. (wire.rs, client.rs)
- Scene builders: prompt_card, thinking_section, assistant_section, tool_card, diff_block, code_block, ansi_block, working_row (spinner+shimmer+elapsed+rate), turn_usage, todo_hud (checklist), composer (badge+effort+meter+editor); theme.rs maps octet theme TOML roles/colors to Tern tokens (accent, muted, border*, userMessageBg, toolDiffAdded, syntax*, …). (scene.rs, theme.rs)
- Reconcile: `reconcile::children` diffs previous vs next keyed by stable node id, emitting only del/add/set/move — appending a turn never detaches prior history; streaming patches one changed `md` leaf via `set`/`text` append. (reconcile.rs)
- Test strategy: per-module unit tests (wire serde + op shape, frame chunking/reassembly with bounds, tty `extract_apc`, reconcile ordering/prop-clearing, scene id uniqueness), plus an integration PTY lane `tests/tern_native_pty.rs` using the real octet binary, a synthetic TSP terminal, isolated HOME/workspace and an inert loopback provider. Reported: 25 unit + 1 doc test; 32 synthetic-TSP PTY checks; 61 checks against actual Tern 0.4.0 headless runtime; a fixtures exporter for offscreen render captures. (docs/design/tern-rail-qualification.md)
- Pain/TODO/gaps: TSP v1 has no per-node colour/CSS so per-turn colours live only in the ANSI renderer; program must advertise `edit` in hello or native selection edits are disabled (the omp snapshot omitted this); Edit events carry no source revision so same-length stale edits are unprovable; native attachment-chip mutation/paste intent unimplemented (rejected+resynced); `settle` eviction not wired; duplicate node ids crash frames (`duplicate id usage.text` dropped octet to ANSI after the 2nd turn -> child ids must derive from the row id); 37 surface families still partially unverified; Tern 0.3.1 untested. (docs/tern.md, qualification ledger, scene.rs tests)
- Patterns worth copying: pure `wire` module (serde enums + custom positional op serializer); `frame` encode/decode with UTF-8-safe splitting and bounded reassembly (MAX_INCOMING_BODY 1MiB, chunks 16, retained 4MiB); credit accounting decoupled from stdin ownership (`connect_shared_input` + `observe`); `has_credit`/`frame_ops_now` returning WouldBlock; keyed reconciler separate from scene builders; theme projection as a table; an explicit policy enum with ANSI fallback; unsafe isolated in one module.

## 4. Do any already bridge ACP?
No. hermes-for-tern speaks Hermes's private `tui_gateway` JSON-RPC (its own protocol), pi-tern uses pi's extension API + Tern CLI/relay, and octet is itself the agent (native Rust). ## 5. Concrete lessons for an ACP->TSP bridge in Rust
- Reuse the established wire contract: octet-tern's `wire.rs`/`frame.rs`/`client.rs`/`reconcile.rs` are a near-drop-in reference; the official `tern-sdk` Rust crate (github.com/stencil-hq/tern-sdk `rust/`) supplies handshake, chunking, credits, keyed diffing and event routing with handlers — evaluate using it rather than forking octet-tern.
- Architecture to adopt: ACP client task owns the agent subprocess (stdio JSON-RPC); a pure reducer maps ACP `session/update` notifications (agent_message_chunk, agent_thought_chunk, tool_call, tool_call_update, plan/available_commands_update/current_mode_update) to an immutable scene model; a keyed reconciler diffs it to TSP ops; ONE input owner owns stdin and routes TSP events (edit/undo/send/action/change/focus/ack) and editor state; a policy/feature gate with an ANSI fallback when Tern is absent.
- Always advertise program hello features you actually handle (`edit` at minimum); never assume; gate optional ops (`scroll`, `settle`, `blobs`) on the terminal reply's advertised features/credit.
- Add region roots as children of the surface id, and derive every child node id from a stable parent id.
- Verify by reading terminal `error`/`ack` events, not by assuming sent frames were accepted (the pi-tern addressing bug survived two milestones this way).
- Map features: streaming text -> md leaf patch (append/splice); thinking -> section+md with shimmer/elapsed; tool calls -> `tool`/`diff`/`code`/`ansi`; permissions -> `card` + `html.button` actions returned as `action` events (then answer ACP `session/request_permission`); cancel -> `session/cancel` from a stop `seg`/Escape; models/modes/commands -> `picker`/`prefs`/`seg`/completion lists; context/cost -> `meter`/`seg`; toasts/notices -> `toast`/dispatch. Keep host ANSI fallback and honor suspend/resume + credit starvation on hidden panes.
- UTF-16 offsets are mandatory for `Edit` events (both octet and hermes validate against them); treat `Text` append vs replace explicitly for streaming.
